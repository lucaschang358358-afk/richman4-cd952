# 大富翁 4 Fun — CD-952 極速流暢 3D 版 v4

專為無敵 CD-952 (240 MHz ARM926EJ-S / Besta RTOS / Project Muteki) 深度效能優化的流暢 3D 版本。

## v4 效能與體驗大升級
1. **徹底解決卡頓（提速 8~13 倍）**：
   - `gfx_fill_tri` 改寫為**零除法 16.16 定點數 DDA 光柵化**，消除 ARM9 軟體除法瓶頸。
   - 新增**靜態場景快取 (`g_bg_cache`) ＋ 局部髒矩形刷新 (`hal_present_rect`)**：轉 3D 骰子、角色跳躍行走、標題 3D 骰子、接金幣小遊戲皆只刷新變動的小區域。
   - 展開式像素填滿迴圈 ＋ `-O3` 編譯最佳化。
2. **徹底消除畫面震動與文字閃爍**：
   - 移除畫面震動特效（爆炸改以衝擊波光環與粒子呈現）。
   - 採用「死區攝影機」：角色在畫面可視範圍內移動時鏡頭 100% 靜止不微晃，離開可視區才一次切換。
   - 靜止選單、AI 思考與報告停頓期間不再重複刷屏，所有中文文字穩定不閃爍。
3. **全域 `[ESC]` 遊戲暫停選單**：
   - 遊戲中任何時候（包含行走中或 AI 回合）按 `ESC` 皆可立即暫停遊戲，開啟暫停選單：繼續遊戲、立即存檔、切換 AI 速度、資產排行、規則說明、返回主標題、存檔離開。
