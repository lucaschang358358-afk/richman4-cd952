# 大富翁 4 Fun — CD-952 3D 立體重製版 v3

專為無敵 CD-952 (ARM926EJ-S / Besta RTOS / Project Muteki) 打造的純整數 3D 軟體引擎版本，免獨立顯示晶片也能流暢運行。

## v3 重大升級
1. **2.5D 斜 45° 等角立體大地圖 + Painter 深度排序**：3 張超大地圖（台灣 64 格、東京 54 格、美國 62 格）升級為 3D 浮島懸崖、3D 凸起石板道路與 3D 擠出立體建築（Lv.0 圍籬到 Lv.5 黃金摩天塔、商業中心、飯店、研究所、醫院、銀行、魔法尖塔）。
2. **真 3D 軟體三軸旋轉立體骰子**：8 頂點 6 面透視投影、背面剔除、三面法線受光與 3D 投影點數，擲骰時在空中立體翻滾彈跳並精準落地。
3. **3D 跳躍動畫人物**：人物與地面陰影分離呈現跳躍高度、附帶 3D 載具（機車/跑車）、頭頂顯眼 `P1~P4` 名牌、動態黃色指向箭頭與移動時剩餘步數倒數氣泡。
4. **全程即時行動播報（不再漏看誰在動）**：
   - 上方醒目動態播報欄：從「輪到誰」→「擲出幾點」→「每一步經過哪裡、還剩幾步」即時更新。
   - 左下角 3 條即時戰報紀錄：保留最新發生的買地、過路費、新聞、用卡事件。
   - AI 行動報告彈窗：AI 每次行動結束都會跳出清楚報告卡片（按空白鍵可立即繼續或切換高速模式）。
