# 大富翁 4 Fun — CD-952 實體機版

專為無敵 CD-952 (Besta RTOS / Project Muteki) 打造的純 C 原生大富翁遊戲，零延遲、免外掛字庫。

## 遊戲功能
- **28 格台灣環島地圖**：小地產 4 色區連鎖加收過路費（Lv0~Lv5）、大型商業用地（商業中心 / 大飯店 / 研究所 / 公園）、台北銀行、點券格、卡片商店、大新聞、魔法屋、醫院、監獄、幸運猜大小賭場。
- **4 位經典角色**：孫小美、阿土伯、錢夫人、沙隆巴斯（可選 1~4 位真人或對戰電腦 AI）。
- **13 種道具卡片**：遙控骰子、烏龜卡、路障卡、停留卡、均富卡、購地卡、怪獸卡、冬眠卡、查稅卡、紅卡、黑卡、飛彈卡、送神卡。
- **台股紅漲綠跌股市**：台積晶圓、長榮海運、大宇娛樂、台北地產（支援漲跌停、紅黑卡操控、每月配息）。
- **5 種神明附身**：財神、福神、土地公、窮神、衰神。
- **即時存檔讀檔**：自動儲存至 `C:\richman4.sav`。

## 操作按鍵
- `方向鍵`：選擇選單與目標
- `Enter` / `空白鍵`：確認 / 擲骰子
- `C`：開啟卡片袋
- `S`：開啟股票市場
- `F`：立即存檔
- `H`：操作與規則說明
- `ESC` / `Backspace`：返回 / 取消
